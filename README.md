# Running the analysis
`test_project_BDA_code.R` caches slow results in `fits/` and saves plots and tables to `outputs/`.
**To rerun a step, delete its file in `fits/`.** See [docs/caching-and-outputs.md](docs/caching-and-outputs.md).
